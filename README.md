# 课程标准生成器（curriculum-standard-generator）

把「专业岗位能力分析」转化为一份可直接备案的**课程标准 .docx**，严格套学校《课程标准》模板。

## 输入（三者缺一不可）

| 输入 | 说明 |
|---|---|
| 专业名称 | 如「智能控制技术」「物联网应用技术」 |
| 课程名称 | 要生成课标的那门课，如「传感器应用技术」 |
| 岗位分析文档 | 一份 Markdown（`.md`），含岗位分类、能力频次、能力→课程映射 |

## 输出

- **仅 `.docx`**（一份课标对应一份 docx）
- 严格套模板版式：封面 + 简介页 + 六章正文（课程性质 / 课程目标 / 教学内容与学时分配 / 考核方式 / 参考教材 / 教学建议）+ 动态表1
- 生成即定稿

## 工作流（4 步）

1. **读岗位分析** → 抽取岗位能力（能力频次排名 + 能力→课程映射）
2. **生成课标内容 JSON**（AI 负责创作，脚本只负责排版）
3. **准备模板母版** → 用 WPS COM 把 `.doc` 转 `.docx`（保留封面/字体/版式）
4. **渲染 docx**

```bash
python scripts/build_docx.py --config 课标内容.json --template 模板.docx --out 输出.docx
```

## 依赖

- `python-docx`（渲染脚本）
- `pywin32`（仅转换 `.doc` 时需要）

详细用法、内容 JSON 字段说明、字体排版规范见 [SKILL.md](SKILL.md)。

## 字体与排版规范

脚本已内置，保证「像人做的」：

- 正文：宋体、小四（12pt）、1.5 倍行距、首行缩进 2 字符
- 章节标题：宋体/黑体加粗小四
- 简介页标签：楷体加粗，值用宋体小四
- 封面表格、表1：宋体，表头加粗居中
- 正文「一、课程性质」自动另起一页
